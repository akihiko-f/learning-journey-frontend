## 学習メモ

### カスタムフックとは

カスタムフックは、**ロジックを再利用可能な関数として切り出す**Reactの機能です。

#### なぜカスタムフックが必要？

**問題: 同じロジックの重複**

```jsx
// TodoApp.jsx
function TodoApp() {
  const [todos, setTodos] = useState(() => {
    const saved = localStorage.getItem('todos')
    return saved ? JSON.parse(saved) : []
  })

  useEffect(() => {
    localStorage.setItem('todos', JSON.stringify(todos))
  }, [todos])

  return <div>...</div>
}

// NotesApp.jsx - 同じコードが繰り返される
function NotesApp() {
  const [notes, setNotes] = useState(() => {
    const saved = localStorage.getItem('notes')
    return saved ? JSON.parse(saved) : []
  })

  useEffect(() => {
    localStorage.setItem('notes', JSON.stringify(notes))
  }, [notes])

  return <div>...</div>
}
```

**解決策: カスタムフック**

```jsx
// hooks/useLocalStorage.js
function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key)
    return saved ? JSON.parse(saved) : initialValue
  })

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value))
  }, [key, value])

  return [value, setValue]
}

// TodoApp.jsx - シンプルになった
function TodoApp() {
  const [todos, setTodos] = useLocalStorage('todos', [])
  return <div>...</div>
}

// NotesApp.jsx - 同じくシンプル
function NotesApp() {
  const [notes, setNotes] = useLocalStorage('notes', [])
  return <div>...</div>
}
```

### カスタムフックの3つのルール

#### 1. 名前は`use`で始める

```jsx
// ✅ 正しい
function useLocalStorage() { ... }
function useToggle() { ... }
function useFetch() { ... }

// ❌ 間違い
function localStorageHook() { ... }
function toggle() { ... }
```

**理由:**
- Reactが「これはフックである」と認識できる
- ESLintのルールチェックが機能する
- 他の開発者が一目でフックだとわかる

#### 2. 他のフックを使える

```jsx
function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(initialValue)  // useState使える

  useEffect(() => {                                  // useEffect使える
    // ...
  }, [key, value])

  return [value, setValue]
}
```

カスタムフック内で、`useState`、`useEffect`、`useContext`など、すべてのReactフックが使えます。

#### 3. コンポーネントではない（JSXを返さない）

```jsx
// ✅ カスタムフック - 値や関数を返す
function useToggle(initialValue) {
  const [value, setValue] = useState(initialValue)
  const toggle = () => setValue(prev => !prev)
  return [value, toggle]
}

// ❌ これはコンポーネント - JSXを返す
function Toggle() {
  return <button>Toggle</button>
}
```

### useLocalStorageフックの詳細

#### 完全な実装

```js
import { useState, useEffect } from 'react'

function useLocalStorage(key, initialValue) {
  // 1. LocalStorageから値を取得
  const [storedValue, setStoredValue] = useState(() => {
    try {
      const item = window.localStorage.getItem(key)
      return item ? JSON.parse(item) : initialValue
    } catch (error) {
      console.error(`Error loading ${key} from localStorage:`, error)
      return initialValue
    }
  })

  // 2. 値が変更されたらLocalStorageに保存
  useEffect(() => {
    try {
      window.localStorage.setItem(key, JSON.stringify(storedValue))
    } catch (error) {
      console.error(`Error saving ${key} to localStorage:`, error)
    }
  }, [key, storedValue])

  return [storedValue, setStoredValue]
}

export default useLocalStorage
```

#### ポイント解説

**useState初期化関数パターン:**
```js
const [storedValue, setStoredValue] = useState(() => {
  const item = window.localStorage.getItem(key)
  return item ? JSON.parse(item) : initialValue
})
```

- 関数を渡すことで、**初回レンダリング時のみ**実行される
- LocalStorageへのアクセスは遅いので、毎回実行するのは無駄
- パフォーマンス向上につながる

**エラーハンドリング:**
```js
try {
  const item = window.localStorage.getItem(key)
  return item ? JSON.parse(item) : initialValue
} catch (error) {
  console.error(`Error loading ${key} from localStorage:`, error)
  return initialValue
}
```

**エラーが起きる場合:**
- LocalStorageが無効な環境（プライベートモード、セキュリティ設定）
- JSON.parseが失敗（データが壊れている）
- ストレージ容量オーバー

エラーが起きても、初期値を返すことでアプリが壊れない。

**useEffectでの保存:**
```js
useEffect(() => {
  try {
    window.localStorage.setItem(key, JSON.stringify(storedValue))
  } catch (error) {
    console.error(`Error saving ${key} to localStorage:`, error)
  }
}, [key, storedValue])
```

- `storedValue`が変更されるたびに実行
- 自動的にLocalStorageに保存される
- エラーハンドリング付き

### useToggleフックの詳細

#### 完全な実装

```js
import { useState } from 'react'

function useToggle(initialValue = false) {
  const [value, setValue] = useState(initialValue)

  const toggle = (newValue) => {
    if (typeof newValue === 'boolean') {
      setValue(newValue)
    } else {
      setValue(prev => !prev)
    }
  }

  return [value, toggle]
}

export default useToggle
```

#### 使い方

```jsx
function Modal() {
  const [isOpen, toggleOpen] = useToggle(false)

  return (
    <>
      {/* 引数なし: 反転 */}
      <button onClick={toggleOpen}>開閉</button>

      {/* 引数あり: 特定の値を設定 */}
      <button onClick={() => toggleOpen(true)}>開く</button>
      <button onClick={() => toggleOpen(false)}>閉じる</button>

      {isOpen && <div className="modal">モーダル内容</div>}
    </>
  )
}
```

#### なぜ便利？

**従来の書き方:**
```jsx
const [isOpen, setIsOpen] = useState(false)

<button onClick={() => setIsOpen(!isOpen)}>開閉</button>
<button onClick={() => setIsOpen(true)}>開く</button>
<button onClick={() => setIsOpen(false)}>閉じる</button>
```

**useToggleを使った書き方:**
```jsx
const [isOpen, toggleOpen] = useToggle(false)

<button onClick={toggleOpen}>開閉</button>
<button onClick={() => toggleOpen(true)}>開く</button>
<button onClick={() => toggleOpen(false)}>閉じる</button>
```

**メリット:**
- コードが短くなる
- 意図が明確になる（トグル用だとわかる）
- 再利用可能

### カスタムフックのメリット

#### 1. コードの重複を削減

同じロジックを複数のコンポーネントで使う場合、カスタムフックに切り出すことで重複を削減できます。

#### 2. ロジックとUIを分離

```jsx
// ❌ ロジックとUIが混在
function TodoApp() {
  const [todos, setTodos] = useState(() => {
    const saved = localStorage.getItem('todos')
    return saved ? JSON.parse(saved) : []
  })

  useEffect(() => {
    localStorage.setItem('todos', JSON.stringify(todos))
  }, [todos])

  return <div>...</div>  // UI
}

// ✅ ロジックが分離されている
function TodoApp() {
  const [todos, setTodos] = useLocalStorage('todos', [])  // ロジック

  return <div>...</div>  // UI
}
```

#### 3. テストしやすい

カスタムフックは独立した関数なので、コンポーネントとは別にテストできます。

```js
// useLocalStorage.test.js
import { renderHook, act } from '@testing-library/react-hooks'
import useLocalStorage from './useLocalStorage'

test('should save to localStorage', () => {
  const { result } = renderHook(() => useLocalStorage('test', 'initial'))

  act(() => {
    result.current[1]('new value')
  })

  expect(localStorage.getItem('test')).toBe(JSON.stringify('new value'))
})
```

#### 4. 再利用可能

一度作ったカスタムフックは、他のプロジェクトでも使えます。

### カスタムフックの実用例

#### 1. useFetch - API呼び出し

```js
function useFetch(url) {
  const [data, setData] = useState(null)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url)
        const json = await response.json()
        setData(json)
      } catch (err) {
        setError(err)
      } finally {
        setLoading(false)
      }
    }

    fetchData()
  }, [url])

  return { data, loading, error }
}

// 使用例
function UserProfile() {
  const { data, loading, error } = useFetch('/api/user')

  if (loading) return <div>Loading...</div>
  if (error) return <div>Error: {error.message}</div>
  return <div>{data.name}</div>
}
```

#### 2. useDebounce - 入力の遅延

```js
function useDebounce(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value)

  useEffect(() => {
    const handler = setTimeout(() => {
      setDebouncedValue(value)
    }, delay)

    return () => clearTimeout(handler)
  }, [value, delay])

  return debouncedValue
}

// 使用例（検索ボックス）
function SearchBox() {
  const [searchTerm, setSearchTerm] = useState('')
  const debouncedSearchTerm = useDebounce(searchTerm, 500)

  useEffect(() => {
    // 0.5秒後に検索実行
    if (debouncedSearchTerm) {
      searchAPI(debouncedSearchTerm)
    }
  }, [debouncedSearchTerm])

  return <input value={searchTerm} onChange={e => setSearchTerm(e.target.value)} />
}
```

#### 3. useWindowSize - ウィンドウサイズの監視

```js
function useWindowSize() {
  const [windowSize, setWindowSize] = useState({
    width: window.innerWidth,
    height: window.innerHeight,
  })

  useEffect(() => {
    const handleResize = () => {
      setWindowSize({
        width: window.innerWidth,
        height: window.innerHeight,
      })
    }

    window.addEventListener('resize', handleResize)
    return () => window.removeEventListener('resize', handleResize)
  }, [])

  return windowSize
}

// 使用例
function ResponsiveComponent() {
  const { width } = useWindowSize()

  return (
    <div>
      {width < 768 ? <MobileView /> : <DesktopView />}
    </div>
  )
}
```

## 理解を深めたポイント

### 1. カスタムフックの設計思想

カスタムフックは「ロジックの再利用」が目的。UIは含めず、純粋にロジックだけを切り出す。

### 2. useStateとの互換性

useLocalStorageは、useStateと同じインターフェース`[value, setValue]`を返すので、既存のコードを簡単に置き換えられる。

### 3. エラーハンドリングの重要性

LocalStorageなどの外部リソースを扱う場合、必ずエラーハンドリングを入れる。アプリが壊れないようにすることが重要。

### 4. 柔軟な設計

useToggleのように、引数の有無で動作を変えることで、より柔軟に使えるフックになる。
