## 学習メモ

### fetch APIとasync/awaitの使い方

fetch APIは、JavaScriptでHTTPリクエストを送信するための標準的な方法です。async/awaitを組み合わせることで、非同期処理を同期的なコードのように書くことができます。

```jsx
const handleSearch = async (e) => {
  e.preventDefault()

  // バリデーション
  if (!city.trim()) {
    setError('都市名を入力してください')
    return
  }

  // ローディング状態を開始
  setLoading(true)
  setError('')
  setWeather(null)

  try {
    // APIリクエスト
    const response = await fetch(
      `https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric&lang=ja`
    )

    // エラーチェック
    if (!response.ok) {
      if (response.status === 404) {
        throw new Error('都市が見つかりませんでした')
      }
      throw new Error('天気情報の取得に失敗しました')
    }

    // JSONデータの取得
    const data = await response.json()
    setWeather(data)
    setCity('')
  } catch (err) {
    // エラーハンドリング
    setError(err.message)
  } finally {
    // 必ず実行される処理
    setLoading(false)
  }
}
```

### ポイント解説

1. **async関数**: 関数の前に`async`をつけることで、その関数内で`await`が使えるようになります

2. **await**: Promiseの結果を待つキーワード。fetchやjson()メソッドは非同期処理なので、awaitで結果を待ちます

3. **try-catch-finally**:
   - try: 通常の処理を記述
   - catch: エラーが発生した時の処理
   - finally: 成功・失敗に関わらず必ず実行される処理（ローディング状態の解除など）

4. **response.ok**: HTTPステータスコードが200-299の範囲ならtrue

### APIのクエリパラメータ

OpenWeatherMap APIに送信しているパラメータの意味：

- `q=${city}`: 検索する都市名
- `appid=${API_KEY}`: APIキー（認証用）
- `units=metric`: 単位を摂氏温度に設定
- `lang=ja`: レスポンスを日本語で取得

### ステート管理の設計

このアプリでは4つのステートを管理しています：

```jsx
const [city, setCity] = useState('')           // 入力された都市名
const [weather, setWeather] = useState(null)   // 取得した天気データ
const [loading, setLoading] = useState(false)  // ローディング状態
const [error, setError] = useState('')         // エラーメッセージ
```

**ステート更新のタイミング**:
1. 検索開始時: loading=true, error='', weather=null
2. 成功時: weather=データ, city='', loading=false
3. エラー時: error=メッセージ, loading=false
4. 完了時（必ず）: loading=false

### CSSアニメーションの実装

#### スピナーアニメーション

```css
.spinner {
  width: 50px;
  height: 50px;
  border: 5px solid #f3f3f3;
  border-top: 5px solid #667eea;
  border-radius: 50%;
  animation: spin 1s linear infinite;
}

@keyframes spin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
```

- `@keyframes`: アニメーションの動きを定義
- `animation: spin 1s linear infinite`: 1秒で1回転、一定速度、無限ループ

#### スライドインアニメーション

```css
@keyframes slideIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.weather-card {
  animation: slideIn 0.3s ease-out;
}
```

- 初期状態: 透明で20px下に配置
- 最終状態: 不透明で元の位置
- 0.3秒かけて滑らかに表示

### グラデーションの使い方

```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

- `135deg`: グラデーションの角度（左上から右下）
- `#667eea 0%`: 開始色（青紫）
- `#764ba2 100%`: 終了色（紫）

### レスポンシブデザイン

@media (max-width: 600px) {

- 詳細情報を縦並びに変更

### 条件付きレンダリング

Reactでは、JavaScriptの論理演算子を使って条件付きレンダリングを実装します：

```jsx
{error && (
  <div className="error-message">
    ⚠️ {error}
  </div>
)}

{loading && (
  <div className="loading">
    <div className="spinner"></div>
  </div>
)}

{weather && !loading && (
  <div className="weather-card">
    {/* 天気情報 */}
  </div>
)}
```

- `error &&`: errorがtrueの時だけ表示
- `weather && !loading &&`: weatherがあり、loadingがfalseの時だけ表示
